# price-tags

1. 사용자가 말한 식물을 슬러그 목록으로 변환한다. "이번 주 들어온 애들"처럼 모호하면 어떤 식물인지 되묻는다.
2. `npm run build -- <슬러그1> <슬러그2> ...` 로 가격표 시트를 해당 식물만으로 생성한다 (페이지는 전체 빌드됨).
3. `node src/pdf.js` 로 `print/price-tags.pdf` 생성. puppeteer 가 없으면 `print/price-tags.html` 을 브라우저에서 열어 "인쇄 → PDF로 저장"(여백 없음, 배경 그래픽 켜기) 하도록 안내한다.
4. 결과 보고: PDF 경로, 카드 수, 시트 수. 점선 테두리가 가위선이고, 코팅 후 QR 스캔을 다시 테스트하라고 안내한다.
