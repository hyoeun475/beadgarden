# care-copy

`plants/*.md` 본문(마크다운 섹션)을 다음 기준으로 다듬는다:

- 다정한 존댓말. 반말·명령조 금지.
- 전문용어 금지. 예: "복토" → "흙 덮어주기", "관수" → "물 주기", "차광" → "빛 가려주기".
- 한 문단 3줄 이내. 이모지는 문단당 1~2개.
- **사실은 바꾸지 않는다** — 물 주기 주기, 빛 조건, 안전 정보는 표현만 다듬는다.
- frontmatter(`---` 사이)는 건드리지 않는다. 특히 `slug` 는 절대 수정 금지.
- 다듬은 뒤 `npm run build` 로 페이지에 반영하고, 바뀐 문장을 전후 비교로 보여준다.
