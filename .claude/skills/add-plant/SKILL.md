# add-plant

1. 식물 이름으로 영문 학명과 영문 슬러그(소문자 a-z, 숫자, 하이픈)를 정한다. `plants/` 의 기존 슬러그와 중복되면 안 된다. **슬러그는 한 번 정하면 절대 바꿀 수 없다** (QR 인쇄됨) — 짧고 명확하게.
2. `plants/<한글이름>.md` 를 기존 파일(예: `plants/몬스테라.md`)과 같은 양식으로 생성한다.
   - 사용자가 말한 값(가격, 물주기, 빛 등)을 우선 반영한다.
   - 비어 있는 항목은 일반적인 식물 상식으로 채우되, 해당 줄 끝에 `<!-- 확인 필요 -->` 주석을 단다.
   - 본문은 손님(식물 초보) 기준: 다정한 존댓말, 전문용어 금지, 한 문단 3줄 이내, 이모지 문단당 1~2개.
3. **`pet_safe` 는 절대 추측으로 채우지 않는다.** 확실한 근거가 없으면 사용자에게 묻는다 (안전 관련).
4. `npm run build` 를 실행하고 QR 디코딩 검증이 통과하는지 확인한다.
5. 결과 보고: 페이지 URL, `dist/qr/<슬러그>.png` 경로, `<!-- 확인 필요 -->` 로 남긴 항목 목록.
